# Introducing Me to the Building

A tiny Node/TypeScript program for the make.fun bounty "One-Liner Marathon". It writes one funny single-line joke to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 280 characters that names the lift.

Entry line:

> I told the lift I was in a hurry, and it stopped at every floor anyway, like it was introducing me to the whole building.

Run it with: `node main.ts`
